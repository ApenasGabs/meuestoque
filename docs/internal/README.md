# docs/internal

Espaço para documentos **não-técnicos** ou de uso interno (planos de contratação, materiais de stakeholder).

Diretrizes:

- Nada aqui deve ser referenciado por código de produção.
- Conteúdo sensível (salários, dados pessoais, contratos) **não pertence ao repositório**, mesmo aqui.
- Permitidos: roadmaps de hiring genéricos, descrições de função, materiais para contribuidores externos.

Motivação: manter a raiz enxuta. Arquivos como `HIRING_PLAN.md` na raiz devem ser movidos para cá em uma operação separada (não automatizada via IA, conforme política do projeto).
