# Hiring Plan: Engineering Team Growth

## 1. Founding Engineer (CTO Level)

### Key Technical Skills
- **Expert React & TypeScript:** Deep understanding of React 19, hooks, and advanced TypeScript patterns.
- **Supabase & PostgreSQL Power User:** Mastery of Row Level Security (RLS), complex RPCs (PL/pgSQL), and database schema design for multi-tenancy.
- **Architectural Vision:** Ability to manage global state (Zustand) and local persistence strategies.
- **Quality Advocate:** Proficiency in Vitest for unit/integration testing and Playwright for E2E testing.
- **CSS Architect:** Strong grasp of Tailwind CSS 4 and UI frameworks like DaisyUI.

### Responsibilities
- **Architecture Ownership:** Maintain and evolve the multi-tenant architecture and data synchronization logic.
- **Security & Scalability:** Ensure RLS policies are airtight and the database scales with group growth.
- **Developer Experience (DX):** Refine the CI/CD pipeline (Vercel, GitHub Actions) and maintain the high testing bar.
- **Product Strategy:** Bridge the gap between CEO vision and technical implementation.

---

## 2. Engineering Roadmap (Next 3 Hires)

### Hire #1: Senior Frontend Engineer (Product & UX Focus)
- **Focus:** Mobile-first responsiveness, UI polish, and complex frontend interactions.
- **Why:** To enhance the user experience as the application scales from a tool to a platform.
- **Key Skills:** Tailwind CSS, Framer Motion, Accessibility (A11y), and performance optimization.

### Hire #2: Backend / Database Engineer
- **Focus:** PostgreSQL optimization, advanced analytics, and external API integrations.
- **Why:** To offload complex data logic from the frontend and manage the growing complexity of stock movement history and FIFO calculations.
- **Key Skills:** PostgreSQL, Redis (if needed for caching), Edge Functions, and Data Engineering.

### Hire #3: Fullstack Engineer (QA & Reliability Focus)
- **Focus:** Strengthening the test suite and bridging the gap between feature development and production stability.
- **Why:** To ensure that as the team grows, velocity doesn't compromise the existing high reliability.
- **Key Skills:** Playwright expert, CI/CD automation, and fullstack React/Supabase development.
